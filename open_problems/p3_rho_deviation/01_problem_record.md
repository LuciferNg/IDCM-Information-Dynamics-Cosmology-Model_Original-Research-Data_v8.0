# P3: ρ Deviation in CKM Unitarity Triangle

## Problem
The Wolfenstein ρ parameter has a structural deviation from the observed value.
IDCM must resolve this without fitting.

## IDCM Result
ρ̄ = φ⁻⁴·(1+ε/2) = 0.1572 (PDG: 0.1570 ± 0.0085)

## Derivation
- ρ correction from P₃ t-channel amplitude
- ε/2 = 0.0773 enters as the t-channel correction factor
- φ⁻⁴·(1+ε/2) = 0.1459 × 1.0773 = 0.1572

## Verification
- PDG: ρ̄ = 0.157
- IDCM: 0.1572
- Deviation: 0.1% (excellent match)
