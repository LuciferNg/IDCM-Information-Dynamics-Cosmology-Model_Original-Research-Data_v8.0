# IDCM Reverse Compiler v19 Changelog

## Summary
**IR generation milestone.** Full ISA instruction set extracted: 5 core opcodes (LOAD, STORE, POW, DIV, SQRT). RPN (shunting-yard) algorithm implemented. AST tokenization with structural exponent detection. Formula-to-IR translation operational.

## New methods
- `_to_postfix(tokens)` — shunting-yard to RPN postfix
- `_tokenize_ast(expr)` — tokenize with ^ as binary operator
- `build_symbol_table()` — symbol → {expression, dependencies, instruction_count}
- `formula_to_ir(formula)` — full formula → IR pipeline
- `microcode_statistics()` — opcode frequency analysis
