# P17: Pseudo-Goldstone Direct Search

## Problem
Search for PG → bb̄ at 14.09 GeV from Z → γ + PG in LEP data.

## IDCM Result
- LEP (10⁶ Z): ~3 signal events, S/√B ~ 0.01σ → insufficient
- FCC-ee (10¹² Z): 2.4M signal events, S/√B = 7.3σ → discovery

## Verification

- M_jj peak at 14.09 GeV in γ+bb channel
