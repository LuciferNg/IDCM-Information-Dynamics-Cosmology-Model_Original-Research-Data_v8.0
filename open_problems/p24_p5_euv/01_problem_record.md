# P24: P₅ EUV Decay Spectrum

## Problem
P₅ at ~84 eV decays via P₅ → νγ. Compute the EUV spectrum.

## IDCM Result
- E_γ = M_P5/2 = 42 eV (EUV)
- λ = 29.5 nm, τ = 78.8 yr
- Flux = 7.7×10⁻¹⁵ erg/cm²/s/sr (undetectable)

## Verification
- 8/8 PASS
- P₅ is NOT dark matter (τ ≪ universe age)
