# IDCM Reverse Compiler v18 Changelog

## Summary
**Canonical dialect trees & confidence.** Rejection Gate formalized: each formula is validated against both dialect-specific grammars, and a dialect confidence score is computed. Introduced canonical tree forms per dialect.

## New methods
- `canonical_forest_for_dialect(formula, dialect)` — forest constrained to dialect grammar
- `canonical_tree_for_dialect(formula, dialect)` — canonical AST per dialect
- `dialect_confidence(formula)` — confidence score (0.0–1.0)
