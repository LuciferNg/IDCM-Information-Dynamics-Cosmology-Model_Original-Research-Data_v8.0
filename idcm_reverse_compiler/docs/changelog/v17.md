# IDCM Reverse Compiler v17 Changelog

## Summary
**Dialect-aware parsing.** Added dialect-specific syntax trees: separate parse strategies for pipeline (sequential `->` chains) and algebraic (`=` assignment) formulas. Forest size reduction for mixed-dialect corpora.

## New methods
- `dialect_aware_forest(formula)` — forest generation respecting dialect binding
- `dialect_aware_parse_tree(tokens)` — dialect-routed parse tree
- `dialect_aware_validate(tree)` — validate structure against dialect rules
- `parse_algebraic_tree(tokens)` — algebraic-specific parse (RPN-ready)
- `parse_pipeline_tree(tokens)` — pipeline-specific parse (state transition)
