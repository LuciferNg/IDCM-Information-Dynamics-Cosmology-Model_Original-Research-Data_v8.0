# IDCM Reverse Compiler v22 Changelog

## Summary
**Execution layer.** v22 adds a VM engine, dependency graph, Unicode corpus cleaner, and V_EW absolute mass scale.

## New Features

### P1: VM Execution Engine (eval_ir)
- Stack machine with 7 opcodes: LOAD, STORE, POW, DIV, ADD, SUB, MUL, SQRT, NEG
- Symbol resolution from mem dict (dependency-ordered execution)
- Returns last stack value (handles STORE popping)

### P2: Automated Verification (verify_all)
- Full pipeline: sanitize → classify → IR → eval → compare
- Dependency-ordered execution
- Error reporting per formula

### P3: Dependency Graph Export
- `export_dependency_graph()` — adjacency matrix + ordered closure chain
- Levels: axiom, primary (eps/beta/kappa), sector_depth (k_*), CKM (V_*), mass ratio

### P5: Unicode/LaTeX Corpus Sanitizer
- Greek letter mapping (φ→phi, ε→eps, κ→kappa, β→beta, etc.)
- Superscript mapping (²→^2, ⁻¹→^-1, etc.)
- Subscript mapping (₀→_0, ₁→_1, etc.)
- Operator mapping (·→*, √→sqrt, ×→*)
- B→4 alias (structural: φ³-φ⁻³=4)

### P5: Implied Multiplication
- `33 beta` → `33 * beta` (adjacent operands)
- Handles number-number, symbol-number, number-symbol, symbol-symbol

### P5: Unary Minus
- `NEG` opcode for `-(expr)` forms
- `-(80 - x)` → `0 80 x SUB NEG`

## Structural Formulas Added
- V_EW/M_P = φ^(4ε² - 80) — VEV/Planck ratio
  - Closure: ✅ (RHS: phi, eps, 4, 80, 2)
  - V_EW = 244.13 GeV (0.85% vs 246.22)
  - m_t = V_EW/√2 = 172.63 GeV (0.077% vs 172.76)
