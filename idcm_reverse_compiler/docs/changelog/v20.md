# IDCM Reverse Compiler v20 Changelog

## Summary
**Automatic formula classification.** Closure propagation algorithm implemented. Formulas are now classified as structural (traceable to φ), fitting (untraceable terms), or input (pure numbers), replacing manual green/yellow marking.

## New methods
- `_build_structural_closure()` — transitive closure of φ-traceable symbols
- `classify_formula_type(formula)` — returns type + confidence + indicators
