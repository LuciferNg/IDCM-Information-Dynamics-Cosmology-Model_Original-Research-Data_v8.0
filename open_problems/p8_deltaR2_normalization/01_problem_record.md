# P8: Δ_R² 振幅歸一化 — RG running from Planck to CMB

## 1. 問題

f(W)R coupling 給出正確嘅 n_s 同 r，但 Δ_R² 偏差 6 個數量級：

| Quantity | f(W)R bare (V₀=1/4096) | Planck 2018 | Ratio |
|:---------|:---------------------:|:-----------:|:-----:|
| Δ_R² | 2.6×10⁻⁴ | 2.1×10⁻⁹ | **1.2×10⁵×** |

**問題：** V₀ = κ/ξ² = 1/4096 M_Pl⁴ 係結構固定值。RG running 能否將呢個振幅壓到 Planck 觀測值？

## 2. 物理機制

### 2.1 Δ_R² 公式
Δ_R²(k) = H²/(8π²·M_Pl²·ε_V)  evaluated at k=aH

H² = V_E(φ_CMB)/(3M_Pl²) = V₀(1-e^{-√(2/3)φ_CMB})²/(3M_Pl²)

### 2.2 RG running
V₀ = κ(μ)/ξ(μ)²

κ(μ) 同 ξ(μ) 嘅 beta function：
- β_ξ = dξ/d(ln μ) = (ξ+1/6)·λ/(4π²) + ξ·λ/(4π²) + ...
- β_κ = dκ/d(ln μ) = 3κ²/(4π²) + κ·ξ²/(4π²) + ...

## 3. RG 計算

從 μ = M_Pl 跑到 μ = 10⁻⁵ M_Pl（CMB 標度）：

### 3.1 ξ running
β_ξ ≈ ξ·λ/(4π²) ≈ 16·(1/16)/(4π²) = 1/(4π²) ≈ 0.0253

ξ(μ_CMB) = 16·exp(0.0253·ln(10⁻⁵)) = 16·exp(0.0253·(-11.5)) = 16·exp(-0.291) = 16·0.748 = 11.96

### 3.2 κ running
β_κ ≈ κ·ξ²/(4π²) ≈ (1/16)·256/(4π²) = 16/(4π²) ≈ 0.405

κ(μ_CMB) = 1/16 + 0.405·(-11.5) = 0.0625 - 4.658 = -4.595

### 3.3 結果
κ 跑到負值 → perturbation theory breaks down！

## 4. 結論
RG running 不能解釋 10⁵× 偏差。ξ=16 同 κ=1/16 嘅組合令理論在 CMB 標度變成 strongly coupled。

## 5. 可能嘅解決方案
1. ξ ≠ 1/κ：如果 ξ 係結構不同數值
2. f(W) ≠ 1 + ξW²：需要不同嘅 coupling 形式
3. Starobinsky inflation 嘅 M 尺度係獨立參數，唔係由 V₀ 決定

## 6. 交叉驗證
Starobinsky (1980): Δ_R² = (M/M_Pl)⁴·(N/3)²/(72π²) = 2.1×10⁻⁹

IDCM: V₀ = 1/4096 M_Pl⁴ → M = √(4V₀/3) = 0.018 M_Pl → Δ_R² = 2.6×10⁻⁴

需要 M/M_Pl ≈ 3.5×10⁻⁶ 先 match Planck → M ≈ 4.3×10¹³ GeV。

IDCM 嘅 V₀ 對應 M ≈ 2.2×10¹⁷ GeV，差 5100×。
